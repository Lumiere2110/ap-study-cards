# 応用情報 暗記カード

応用情報技術者試験の勉強用に作った、**Anki 風の間隔反復（スペース・リピティション）暗記カードアプリ**です。
インストール不要・ビルド不要の Web アプリ（PWA）で、PC でもスマホでも使えます。

## できること

- **科目（デッキ）ごとに整理** — テクノロジ系 / マネジメント系 / ストラテジ系 / 午後対策 / その他 の分野別に表示。
  シラバスに沿った科目セット（基礎理論・ネットワーク・セキュリティ・データベース…）をワンクリックで作成できます。
- **一問一答の問題集を内蔵** — 全科目で約300問の一問一答カード（解説付き）をワンクリックで追加。
  問題集が増えたときは同じボタンで未登録の問題だけが追加されます（学習記録はそのまま）。
- **自由なテキスト入力** — 表（問題）・裏（答え）・解説メモ・タグ
  - `{{答え}}` で **穴埋めカード**（`{{答え::ヒント}}` でヒント付き）
  - `**太字**` / `==マーカー==` / `` `コード` `` / ```` ``` ```` で複数行コード（擬似言語など）
- **写真・画像の挿入** — ファイル選択、スマホでの撮影、`Ctrl+V` 貼り付け、ドラッグ&ドロップ。
  大きな写真は自動で縮小して保存。学習中はタップで拡大表示。
- **Anki 方式の復習スケジュール** — 「もう一度 / 難しい / 正解 / 簡単」の4段階評価で、次の出題日を自動調整（SM-2 ベース）。
- **★ 苦手カード** — マークしたカードだけを集中練習（自由練習はスケジュールに影響しません）。
- **カード一覧・検索** — キーワード / `#タグ` / 状態（苦手・間違えたことがある 等）で絞り込み、並べ替え。
- **学習の記録** — 学習カレンダー、連続学習日数、正答率、科目別の定着率、よく間違えるカードのランキング。
- **バックアップ** — 画像込みで 1 つの JSON ファイルに保存・読み込み（端末間の移行にも）。
- ダークモード対応、キーボードショートカット対応（`Space` 答え表示 / `1`〜`4` 評価 / `F` 苦手 / `E` 編集 / `Z` 取り消し）。

## 使い方

### PC でそのまま使う

`index.html` をダブルクリックしてブラウザ（Chrome / Edge 推奨）で開くだけで使えます。

> ローカルサーバーで開くとオフライン対応（PWA）も有効になります:
> ```
> python -m http.server 8765
> ```
> → http://localhost:8765 を開く

### スマホでも使う（おすすめ）

GitHub Pages などで公開すると、スマホのブラウザから開いて「ホーム画面に追加」でアプリのように使えます。
苦手問題をその場で撮影して登録するのに便利です。

1. このリポジトリを GitHub に push
2. リポジトリの Settings → Pages → Branch: `main` / `/ (root)` を選んで Save
3. 表示された URL をスマホで開き、共有メニューから「ホーム画面に追加」

## データの保存について

- カード・画像・学習記録は **使っているブラウザの中（IndexedDB）** に保存されます。サーバーには送信されません。
- PC とスマホのデータは別々です。移したいときは「設定 → バックアップを保存」したファイルを、もう一方の「バックアップを読み込む」で取り込んでください（同じカードは上書き、それ以外は追加）。
- ブラウザのサイトデータを消すとカードも消えます。**定期的にバックアップ**してください。

## 構成

```
index.html            画面の骨組み
css/style.css         デザイン（ライト/ダーク）
js/util.js            DOM ヘルパー、日付、本文レンダリング（穴埋め等）、画像圧縮、設定
js/db.js              IndexedDB ラッパー、画像 URL キャッシュ
js/srs.js             間隔反復スケジューラ（Anki SM-2 方式）
js/questions.js       組み込みの一問一答問題集
js/store.js           科目・カード・統計・バックアップのデータ操作
js/components.js      ダイアログ、カード表示、カード編集フォーム
js/views.js           各画面（ホーム / 追加 / 学習 / 自由練習 / 一覧 / 記録 / 設定）
js/app.js             ルーター・起動処理
sw.js                 オフライン用 Service Worker
manifest.webmanifest  PWA 設定
```

フレームワーク・ビルドツールは使っていない素の HTML / CSS / JavaScript です。

### スケジュールの仕様（Anki 準拠）

| 状態 | もう一度 | 難しい | 正解 | 簡単 |
| --- | --- | --- | --- | --- |
| 新規・学習中 | 1分後 | 6分後 / 同じステップ | 次のステップ（1分→10分→1日） | 4日後 |
| 復習 | 10分後に再学習（間隔は半分、易しさ −20%） | 間隔×1.2（易しさ −15%） | 間隔×易しさ（初期 2.5） | 間隔×易しさ×1.3（易しさ +15%） |

- 1日の区切りは午前4時（夜遅くの学習が翌日扱いにならないように）
- 新規カードは科目ごとに 1日 20 枚まで（設定で変更可）
